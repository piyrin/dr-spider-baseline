## 代表错误的原因复核

每例在同一数据库上执行标准 SQL、原预测和只修改一处的预测。沿用批测的结果比较函数。七例修改后均与标准结果一致。[完整 SQL 和数据库检查结果](../results/diagnostics/sql-diagnostics.json)

| 样本 | 单点修改与执行证据 | 差异原因 |
| --- | --- | --- |
| `DB_schema_synonym-02040-post` | 增加 `EXISTS`，要求候选国家至少有一条语言记录。结果从 179 行变为标准的 173 行。独立检查发现恰有 6 个国家没有语言记录。 | 预测从全部国家构造候选集，标准 SQL 仅纳入有语言记录的国家。 |
| `DB_schema_abbreviation-01515-post` | 将 `'Yes'` 改成 `'yes'`，从 0 行变为标准的 1 行。实际 `hd` 值只有 `no`（14 行）和 `yes`（1 行）。 | 等值过滤中的字面值大小写导致空结果。 |
| `NLQ_keyword_synonym-00147-post` | 去掉 `CAST(Horsepower AS INTEGER)`，计数从 49 恢复为标准的 281。额外计入的 232 行都以文本存储，例如文本 `'90'` 在 SQLite 的文本比较中大于 `'150'`。 | 标准 SQL 使用 `TEXT` 比较，预测显式做数值比较，因此会纳入不同的行。 |
| `NLQ_column_synonym-00019-post` | 将输出的 `cm.FullName` 改为 `cm.Maker`。两次均返回 11 行，修改后返回值与标准一致。 | 预测输出厂商全名，标准 SQL 输出厂商简称。 |
| `NLQ_column_synonym-00378-post` | 将 `Name = 'United States'` 改为 `GovernmentForm = 'US Territory'`。聚合对象从美国本身变为 3 个领土，结果由 `(8510700.0, 278357000)` 变为标准的 `(510.3333333333333, 329000)`。 | 预测筛选国家名称，标准 SQL 筛选政府形式。输入改写也将 GNP 换成了 GDP，两条 SQL 均聚合 `GNP`。 |
| `SQL_sort_order-00171-pre` | 去掉次排序键 `grade`，结果从 9 变为标准的 12。9 至 12 年级各有 4 人，全部并列。 | 两条 SQL 均选中一个人数最多的年级，次排序键改变了所返回的并列项。 |
| `NLQ_keyword_synonym-00281-pre` | 将预测中的 `'Jetblue Airways'` 改为 `'JetBlue Airways'`，计数从 0 变为标准的 100。实际航司表存在后者。 | 预测的字面值大小写与库值不同，导致等值条件未匹配到航司。 |

单点复核的结果对应所列样本和数据库。存在多种合理解释的案例仍按原评分口径计入基线 EX。
