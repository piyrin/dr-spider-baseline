# 任务1 · Dr.Spider 基线实验报告

## 数据与实验设置

本实验使用 Dr.Spider 的扰动前（pre）和扰动后（post）配对问句，以自然语言问题和 SQLite 表结构作为模型输入。固定版本的数据包含 17 类扰动和 15,269 个配对实例，基于 Spider-dev 的 1,034 道原题。同一道原题可能出现在多个扰动类别中。两批实验覆盖其中五类。[数据来源](../manifests/data_source.json) · [数据盘点](../manifests/data_inventory.json) · [五类配对案例](问题记录.md#五类配对案例)

| 项目 | 设置 |
| --- | --- |
| 运行日期 | 2026 年 11 月 18 日（北京时间） |
| 模型与参数 | Thingo API 的 `gpt-6-sol`。关闭流式响应，其余参数沿用服务端默认值。服务端未提供模型 digest 或 `system_fingerprint`。 |
| 配对抽样 | 五类扰动分别无放回抽样。首批每类 5 对（种子 42），主批每类 10 对（种子 43）。每对选取同一下标的 pre 和 post。 |
| 输入与输出 | 输入完整的 SQLite 建表语句和自然语言问题，要求模型只返回一条 `SELECT` 查询。 |
| 评分口径 | 在每题对应的单个 SQLite 库上比较预测与标准 SQL 的执行结果。数据库扰动的 post 使用扰动后的库。保留字面值与 `DISTINCT`，按标准 SQL 的 `ORDER BY` 决定是否比较行序。 |

每批结果文件记录样本标识、预测 SQL、评分，以及运行时的源码哈希、依赖版本与评测实现版本。[25 对首批](../results/baseline/sol-25pairs.json) · [50 对主批](../results/baseline/sol-50pairs-seed43.json)

## 实际错误分布

分母为主批的 31 个执行结果不一致侧。每侧按预测和标准 SQL 的主要差异计入一个类别。部分样本存在多处差异。首批的 6 条不一致单独列出。[逐题标签与诊断记录](问题记录.md#执行结果不一致样本)

| 主要差异 | 问题侧数 | 占 31 个不一致侧 |
| --- | ---: | ---: |
| 关联或候选集合 | 11 | 35.48% |
| 类型或日期转换 | 6 | 19.35% |
| 输出列 | 5 | 16.13% |
| 排序及并列规则 | 4 | 12.90% |
| 筛选或统计粒度 | 3 | 9.68% |
| 文本常量大小写 | 2 | 6.45% |

## 结论

50 对主批的 EX 从 **72%（36/50）降至 66%（33/50）**。问题列名同义表达下降最多，从 60% 降至 30%。排序类在首批下降 20 个百分点，在主批上升 10 个百分点，两批样本的变化方向不同。

主批最常见的差异是关联或候选集合，占 31 条不一致中的 11 条。七条代表预测各修改一处 SQL 后均与标准结果一致。JetBlue 对照中，原问句复测返回 0，只调整问句中航司名的大小写后返回 100，与标准一致。[SQL 诊断](问题记录.md#代表错误的原因复核) · [JetBlue 对照](../results/diagnostics/jetblue-model-control.json)

结论限于抽取的样本和对应的单个 SQLite 库。并列选取、文本比较和关联范围会影响执行评分。JetBlue 对照每种问句各新增一次请求。
