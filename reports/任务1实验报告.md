# 任务1 · Dr.Spider 基线实验报告

## 数据与实验设置

Dr.Spider 将问题组织为扰动前（pre）和扰动后（post）的配对样本。固定版本的数据包包含 17 类扰动、15,269 个配对实例，来源为 Spider-dev 的 1,034 道原题。同一道原题可能出现在多个扰动类别中。本实验选择其中五类，输入自然语言问题和 SQLite 表结构，评测模型生成的 SQL。例如，原题 879 将“找学生最多的年级”改成“找学生最少的年级”，标准 SQL 的排序由降序变为升序。数据来源、版本和实例如下。[数据来源清单](../manifests/data_source.json) · [数据盘点](../manifests/data_inventory.json) · [五类配对案例](问题记录.md#五类配对案例)

| 项目 | 实际设置 |
| --- | --- |
| 实验批次与日期 | 2026-11-18 北京时间。抽取5类，`sol-25pairs` 每类 5 对，`sol-50pairs-seed43` 每类 10 对。 |
| 模型 | Thingo API，请求 ID 与全部 150 个响应返回的模型名均为 `gpt-6-sol`。digest 和 `system_fingerprint` 均为空，记为未知。 |
| 抽样方法 | 各类别内无放回随机抽取下标。25 对使用种子 42，50 对使用种子 43。同一 `group/index` 同时取 pre、post。样本身份、原题号与数据库哈希见各批次 `plan.json`。 |
| 提示词与请求参数 | 系统提示要求根据问题和表结构生成一条 SQLite SELECT 查询，只输出 SQL，保留必要的值。用户消息为完整建表语句和问题。显式设置 `stream=false`，其余生成参数采用供应商默认值。 |
| 代码与依赖 | 运行时 HEAD 为 `c972bac074c06419187a3e77432118b242bd3362`，工作区有未提交改动。两批的三份源码哈希和依赖清单一致。API 脚本的 Git 文件与实验原件字节一致。`src/baseline.py` 在实验工作区使用 CRLF，在 Git 中保存为 LF，统一行尾后内容一致。 |
| 评测实现 | 比较函数来自上游提交 `e97acc546ecbee8fa27fa8dbf025ef61493a876c`。在每题对应的单个 SQLite 库上执行预测与标准 SQL，比较结果是否一致。 |
| 数据库及 SQL | DB 类 post 使用扰动后的数据库。保留实际值与 `DISTINCT`，按标准 SQL 是否含 `ORDER BY` 决定比较时是否考虑行序。 |
| 结果证据 | [25 对首批](../results/sol-25pairs.json)和[50 对主批](../results/sol-50pairs-seed43.json)包含配置、环境、逐题预测与标签。完整请求和响应保存在本地 `runs/<批次名>-<样本ID>/`，导出记录提供相应的 SHA-256。 |

## 结果与局限

- 50 对批次中，问题列名同义表达的 post 得分最低（3/10），较该类 pre 下降 30 个百分点。排序类在首批下降 20 个百分点，在本批上升 10 个百分点。这两个小样本中观察到的方向不同。
- 主批 31 条不一致中，最常见的是关联或候选集合差异，占 11/31。两批共选七处差异做单点修改，修改后均通过同库执行比较，覆盖候选集合、文本字面值、类型转换、输出列、筛选条件和并列规则。[逐例诊断](问题记录.md#代表错误的原因复核)
- JetBlue 对照中，原问句复测再次生成 `Jetblue Airways`，计数为 0。只改问句中名称的大小写后，新预测计数为 100，与标准一致。每种条件新增一次请求，证据限于该题。[对照记录](../results/jetblue-model-control.json)
- 本报告的 EX 限于所抽到的配对和配套单库。遇到并列选一、文本类型或关联范围的情况，应结合题意和标准 SQL 的假设解读分数。后续 Agent 实验可以在相同样本上检验值匹配、字段选择和类型检查是否改善结果。[工程阅读记录](rsi-data阅读记录.md)
